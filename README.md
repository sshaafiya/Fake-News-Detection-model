# 📰 Fake News Detection Model using TensorFlow

A deep learning-based Fake News Detection system that classifies news articles as **FAKE** or **REAL** using Natural Language Processing (NLP) and an LSTM neural network built with TensorFlow.

---

## 📌 Objective

The objective of this project is to develop a deep learning model capable of identifying whether a given news article is **fake or real** based on its textual content.

The project uses:

- Natural Language Processing (NLP)
- Text preprocessing
- Tokenization
- Word embeddings
- LSTM (Long Short-Term Memory)
- Binary classification
- TensorFlow / Keras

---
